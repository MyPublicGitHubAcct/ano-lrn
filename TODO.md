### Add time-domain pitch shifter

Add `pitch_shift(signal, fs, semitones)` to `src/python/delay/pitch_shift.py`. A single-buffer pitch shifter uses two overlapping fractional-delay read heads traversing the delay buffer at a rate of `(2 − r)` samples per step, where `r = 2^(semitones / 12)`, while the write pointer always advances at 1 sample per step. Each read head is windowed with a Hann envelope of length equal to the buffer; when a head reaches the buffer boundary it wraps and the two heads are phase-staggered by half the buffer length so one always fades in as the other fades out. Sub-sample read positions are resolved by `fractional_delay_line`. Add tests verifying: the dominant FFT frequency of a sine input shifts by the expected ratio within 1%, the output length equals the input length, and `semitones = 0` returns the input within floating-point rounding. ### Add one-pole filter

### Add wavefolder distortion

Add `wavefold(signal, gain)` to `src/python/virtual_analog/distortion.py`. A wavefolder reflects the signal back each time it would exceed ±1, producing mirror images of the waveform rather than clipping it: while any sample exceeds 1, apply `sample = 2 − sample`; mirror symmetrically for negative values. At `gain = 1` the signal is folded once per half-cycle; at `gain = 2` twice; and so on. Higher fold counts produce richer harmonic content than clipping because the fold adds a new partial each time a boundary is crossed. Add tests verifying: output is bounded to [−1, +1] for all gains, FFT harmonic energy above 2× the fundamental increases monotonically with `gain`, and `gain = 0` produces silence. Add `plot_virtual_analog_distortion.py` showing a sine wave folded at gains 0.5, 1, 2, and 4. Wavefolding is a defining feature of Buchla synthesizers and is directly relevant to the VCV Rack VA module set.

### Add Aeolian wind harp (vortex-induced string vibration)

Add `plot_physical_aeolian.py` showing a wind-speed sweep: a spectrogram in the top panel with bright lock-in bands at each harmonic frequency appearing and disappearing as `wind_speed` crosses threshold, and the Strouhal shedding curve overlaid as a diagonal line. No other instrument in this codebase is driven by a fluid — this is the only physical model where the player is the wind.
